# PowerZone - Premium Gym Membership Website

## Project Overview

PowerZone is a modern, premium fitness membership platform designed to revolutionize the gym experience. This single-page web application showcases a sophisticated dark-themed interface with a focus on user engagement and visual appeal.

## Key Features

**Hero Section**
- Cinematic full-viewport hero with motivational messaging: "NO HESITATION. FULL COMMITMENT."
- Dynamic background image integration
- Prominent call-to-action button for user conversion
- Smooth parallax scrolling effects

**Navigation**
- Transparent glassmorphic navbar with smooth scroll behavior
- Pill-shaped navigation container with glossy hover effects
- Separate Login and Register buttons for clear user actions
- Responsive design adapting to all screen sizes

**Features Section**
- Four service offerings: FITPASS, FITCOACH, FITFEAST, and FITPASS-TV
- Clean white card design on light background
- Horizontal scrollable layout with smooth animations
- Image-driven content presentation

## Technology Stack
- Pure HTML5, CSS3, and JavaScript
- No external frameworks or dependencies
- Optimized for performance and accessibility
- Mobile-responsive design

## Design Philosophy
PowerZone combines Apple-like minimalism with Equinox gym's luxury aesthetic, creating an exclusive, high-end fitness brand experience that appeals to premium urban professionals.
